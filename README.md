# StuHelper Open Platform

第三方应用审批、逐项用户授权与撤回通知模块。模块拥有独立 PostgreSQL schema `open_platform`，业务数据通过公开接口读取。使用 AGPL-3.0-only。

## 当前实现

开发者提交名称、用途、HTTPS 回调与信息范围。管理员逐项审批并设置授权期限、令牌期限和 UTC 日调用配额。登录不会自动授予业务信息权限。

稳定范围为 student_status、schools、qq_binding_status、qq_binding_details、profile、schedule、catalog、public_reviews。目录与公开评价仍由提供方执行当前内容准入。课表读取本人有效选课记录对应的排课，空 meetings 表示没有提供排课，不能推断用户空闲。

QQ 两档分别申请、审批和授权，同意页 qq_tiers 表明“绑定状态”或“绑定状态和号码”。状态档不返回号码。两档必须来自可信绑定来源，缺失或故障返回 503。

授权使用单次授权码与 PKCE S256，精确匹配登记回调。每个账号最多保留 100 个未过期、未决定的授权请求。用户会话创建 5 分钟授权请求，服务端绑定本人、应用修订、范围、回调和 state。决定返回回调 URL，客户端必须核验 state 与 iss。授权码有效 60 秒。

应用类型为 public 或 confidential。两类均要求 PKCE，confidential 还要求 HTTP Basic 应用凭据。访问令牌最长 1 小时，不发行刷新令牌；交换结果不明时重新发起授权。业务令牌不接受作为用户会话。

应用凭据仅首次轮换返回明文，持久化哈希。相同幂等键重试返回 retrievable=false；丢失响应后读取修订并重新轮换。授权码由私钥 MAC 派生，库中只存哈希，幂等结果不包含 code。CodeKey 必须为 32 随机字节，由私有配置管理。

每次业务读取前后检查当前应用、授权、期限和账号状态。撤回范围使已有令牌立即失效；保留范围需要新授权码换取新令牌。管理员变更使原授权失效，重新启用需用户重新授权。

注销在同一事务封存授权账号、停用名下应用。每个开发者最多 100 个应用。恢复由管理员另行处理；模块没有自动复活账号或旧令牌的入口。

Work 每批最多 100 条、最多 10 秒，为到期、停用与注销授权生成通知。即时拒绝读取不依赖后台进度。第三方通过应用凭据或开发者会话分页读取通知，顺序游标支持继续读取后续通知。

通知支持 received、deleted 和 retention_exception 回报，法定保留例外必须填写理由。seen_at 仅表示读取，deleted 仅记录第三方声明。已停用应用的凭据只可读取和反馈通知，不能恢复数据权限。

列表每页最多 100 条。提供方调用限时 3 秒，数据库操作限时 5 秒。应用日配额在真实数据库原子扣减，授权后的调用尝试包括提供方失败均计入。模块不缓存第三方读取的业务数据。

业务记录、必要审计与幂等结果同事务提交。

Cleanup 每类最多清理 100 条、总计最多 600 条，整轮最长 5 秒。幂等响应完成 24 小时后清理，过期令牌即时清理，授权请求过期 24 小时后清理，事件与通知保留 12 个月，日配额保留当前与前一 UTC 日期。数据库备份与保留由私有运维策略管理，不增加付费存储或上传检查产物。

## 接口与检查

接口定义见 [OpenAPI](contracts/open-platform.openapi.json)，生成客户端位于 sdk。运行 `make generate` 更新客户端，`make check` 检查生成一致性、仓库边界、文档、竞态与真实 PostgreSQL。

检查需要 STUHELPER_OPEN_PLATFORM_TEST_DSN 指向隔离测试服务器。CI 使用最新稳定 PostgreSQL。业务运行身份仅获得本 schema 的表权限，requests、events 和 tokens 允许 SELECT、INSERT、DELETE，禁止 UPDATE，序列只允许 USAGE。迁移身份单独使用。

## 验收场景

| 场景 | 检查 |
| --- | --- |
| OP-01：申请和审批 | 非管理员拒绝、未审批拒绝、批准范围与用户范围交集、回调和 PKCE 绑定、事务回滚 |
| OP-03：授权失效 | 部分撤回、在途读取撤回、单次交换、过期、配额、账号注销与可恢复通知 |
| OP-04：登录不自动授权 | 用户会话不能替代业务令牌，伪造 owner 和未知字段被拒绝 |

真实账号、第三方应用联调和生产迁移未验收。后端组合负责连接事实提供方并启动有界后台处理。本仓不包含客户端页面或生产配置。

授权码重放在验证应用、回调和 PKCE 后撤销该授权码签发的令牌。错误证明不能撤销令牌，其他应用授权不受影响。profile.id 与返回 subject 相同，按应用隔离，不返回全局个人主页 ID。

QQ 来源由 qq-binding 提供。三项独立身份全部验证后才返回绑定完成，详情范围仅包含 OneBot 的 QQ 号，不含 openid 或 unionid。任一项解绑后返回未完成且不返回号码；来源故障返回 503。
